## Profile 3 — DevOps Engineer (software engineering)

A DevOps Engineer automates how software is built, tested and deployed.
The role joins development and operations through scripting, containers,
continuous integration and cloud services.

| Order | Category | Canonical symbols | Rule |
|---|---|---|---|
| 1 | Scripting | PYTHON, BASH | at least one |
| 2 | Containers | DOCKER | required |
| 3 | Orchestration | KUBERNETES | optional |
| 4 | CI/CD | JENKINS, GITHUB_ACTIONS, GITLAB_CI | at least one |
| 5 | Cloud | AWS, AZURE, GCP | at least one |
| 6 | Version control | GIT | required |

Example: Git, AWS, Jenkins, Docker, Python → PYTHON, DOCKER, JENKINS, AWS, GIT

## Profile 4 — Data Engineer (AI/data)

A Data Engineer builds the pipelines that collect, transform and store data
so analysts and ML models can use it.

| Order | Category | Canonical symbols | Rule |
|---|---|---|---|
| 1 | Programming | PYTHON, SCALA | at least one |
| 2 | Query language | SQL | required |
| 3 | Data processing | SPARK, HADOOP, KAFKA | at least one |
| 4 | Orchestration | AIRFLOW | optional |
| 5 | Databases | POSTGRESQL, MYSQL, MONGODB | at least one |
| 6 | Cloud | AWS, AZURE, GCP | optional |
| 7 | Version control | GIT | required |

Example: Git, Postgres, Kafka, SQL, Python → PYTHON, SQL, KAFKA, POSTGRESQL, GIT
